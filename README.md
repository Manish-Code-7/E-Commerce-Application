# The Collective - E-Commerce Application

A modern, responsive e-commerce website built with HTML, CSS, and JavaScript.

## Features

- 🛍️ Multi-category shopping (Men, Women, Kids, Shoes, Beauty, Jewellery, Home & Decor)
- 🛒 Shopping cart functionality
- ❤️ Wishlist feature
- 👤 User authentication (Login/Signup)
- 📱 Responsive design
- 🎨 Modern UI with smooth animations
- 💳 Payment and shipping flow

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Bootstrap 5.3.0, Font Awesome 6.4.0
- **Hosting:** Vercel

## Deployment

This project is configured for deployment on Vercel.

### Deploy to Vercel

1. **Install Vercel CLI (optional):**
   ```bash
   npm install -g vercel
   ```

2. **Deploy:**
   ```bash
   vercel
   ```

   Or simply push to your Git repository and import it to Vercel dashboard.

### Vercel Configuration

The project includes:
- `vercel.json` - Configuration with security headers and caching
- `.vercelignore` - Files to exclude from deployment
- `index.html` - Root entry point
